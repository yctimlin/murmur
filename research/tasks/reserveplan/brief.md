Build **reserveplan**, a small offline Python tool for planning jobs against shared resources. This is a new project: the input repository contains the product specification and example JSON, but no implementation. Implement the package, command-line entry point, documentation, and your own tests. Use only the Python standard library, and keep the project installable with `pip install --no-deps --no-build-isolation .`. Organize the code into separate modules for validation, planning, and command-line behavior.

The full contract is in `SPEC.md`. The main use is `python -m reserveplan plan jobs.json`, which emits a deterministic reservation plan. People need to reserve machines and staff around existing bookings and downtime, honor prerequisite jobs, and see lateness. Also expose `reserveplan.plan(spec)`, `reserveplan.validate(spec)`, and `reserveplan.PlanError` for library callers. Implement the documented failure behavior, stdin/file output, and CSV export as well as the scheduling rules. Please leave a concise `PR.md` describing the delivered behavior and how you checked it.
