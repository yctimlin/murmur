# Operator grading design

129 equally weighted independent unittest cases. The suite covers deterministic transitions and exact response/state shapes, DAG joins and cascades, expiry boundaries and fencing, exponential retry, cancellation, typed idempotency, detached values, transaction/iterable rollback, persistence and concurrent processes, audit export/load corruption, strict JSON CLI, schema and graph failures. Tests use concrete expected outcomes and do not import the positive-control reference. Test IDs remain fixed when frozen; partial credit is passed/129, not number of individual assertions.

The public input contains SPEC.md, README.md, examples/batch.json and .gitignore only. `controls/` and `hidden/` are never copied into input. `make_input.sh` is deterministic and refuses to overwrite an existing input. The untouched input fails129/129 because no implementation exists. Author reference passes129/129. `controls/check.py` recreates both and eight defect controls; results live in research/data/workflow_store-controls/. All are local deterministic checks, not model calibration and not runner mutation scores. Cross-checks do not prove complete specification coverage or task difficulty.

Scoring copies the supplied delivered tree, dereferences links, ignores .git/.venv/__pycache__, sets PYTHONPATH for flat/src packages, and never modifies the supplied tree. Each case has a new temporary SQLite file. CLI subprocesses have12s limits, long-chain/batch checks15s, concurrent-worker checks25s per communication, outer suite600s. Stderr diagnostics are bounded, final stdout is JSON passed/total/rate. A whole-suite timeout or crash yields0/129; most product errors fail only the relevant case. No network or third-party packages are required. Scoring does not install the package, so packaging, docs, PR.md and architecture remain task requirements but are not graded proxies.

The task is frozen before exec calibration. It must meet the operator gate and stricter C2 per-run gate before swarm use. Do not change a frozen task in response to model outputs. The substantial task-author time estimate is uncalibrated; only C2 establishes whether this is a suitable long task.
