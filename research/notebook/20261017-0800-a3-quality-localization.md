# Historical P0/P1 localization

- Question: Which retained source files/authors/phases and peer seams accompany judge-flagged high-severity failures?
- Method: Parse every severity-bearing finding in retained adversarial Markdown referenced by the historical index. Resolve source references, byte-compare each judged implementation file to the original run's final main, and git-blame original history. Add seven transparent manual source-location annotations where reports name methods but omit filenames. Count explicit seam claims separately from cited-line multi-peer authorship. No historical candidate/reproducer or new lab job is executed.
- Prediction: Snapshot-boundary and schema/query cases should recur; judge module seams will not all be cross-peer seams. Flattened judge git snapshots will be inadequate for authorship.
- Raw-data paths: original report paths are recorded in `research/data/quality_findings.csv`; original run repositories come from `index.csv`. Methods/tool: `research/data/QUALITY_METHODS.md`, `research/tools/localize_quality.py`; manual source anchors: `research/data/quality_annotations.json`.
- Result: **230 findings = 121 P0 + 109 P1** in **78 report files**. All findings now have at least one attributed implementation location, with every used file byte-identical to original final main. All retained numeric P0/P1 run aggregates reconcile, averaging two passes for round 2. **18** findings have explicit judge seam claims and >=2 peer authors on exact cited/source-inspected lines (**14 P0**, **4 P1**); 21 further swarm claims lack that authorship support. Eleven early judge sources have no retained adversarial Markdown. Four explicit absent-app findings correctly blame only inherited input code; missing entrypoint code cannot have an author.
- Limits: Findings are judge-pass observations, not unique defects or fresh reproductions. Source-line phase means last blamed change, with ancestry-based draft/preexisting labels and explicit subject heuristics for other phases; omissions and copy provenance prevent exact causal introduction dating. Older reports often omit seam labels. Failure-mode categories are descriptive title rules, not experiment results.
- Decision: Supply this inventory to a1 for a peer review and join into DIAGNOSIS/index summaries. Avoid claiming the seam subset or draft-origin lines explain the protocol's causal quality loss.
